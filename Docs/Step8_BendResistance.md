# 段階8: 押し戻しの攻略ルール

[ドキュメント一覧](README.md) / [現在のContactシーン](ContactSock_Physics.md)

> この文書は段階別の開発記録です。数値・操作・「次の段階」は当時の実装を対象にしています。現在の操作と調整はContactシーンのガイドを参照してください。

実装日: 2026-09-10

## 起動と操作

1. Unity 2021.3.45f2で `Sock Physics > Open Step 8 Scene` を選び、Playする。
2. 明るい緑の脚を左ドラッグし、足をまっすぐに保って曲がり部分へ押し当てる。
3. 右上に `PULL LEFT` が出たら、脚を左へ引き戻す。`PUSH RIGHT` に変わったら再度押す。
4. 4回の押し当てで抵抗が100 → 75 → 50 → 25 → 0になる。
5. `READY` が出たら少し戻し、Qで足首を-90度付近へ曲げ、脚を右下へ移動する。
6. 足先・かかと・足首・脚を合わせて静止するとクリア。Rまたは再挑戦ボタンで全体を戻す。

シーンは `Assets/Scenes/BendResistance.unity`。Gameビューは16:9、960×540以上が目安。段階1〜7のシーンとBuild Settingsは変更しない。

## 押し当てと引き戻し

BendControllerは指定した曲がり外側のColliderと足の接触だけを対象にする。判定条件は次のとおり。

- 足と対象Colliderの距離が0.03以下。
- 脚を右へ押そうとしている（ドラッグ目標が脚より右へ0.2以上）。
- 足の実際の角度が水平から15度未満。
- この条件が0.12秒続く。

成立すると25減らし、次の押し当てを一旦無効にする。再び有効にするには接触を離し、左向きのドラッグを続けながら、成立時の脚の位置より0.35以上左へ戻る必要がある。単にマウスを離す、押し続ける、細かく揺らすだけでは次の回数にならない。

InspectorでInitial Resistance、Reduction Per Push、Push Duration、Return Distanceを調整できる。基準の動作検証は既定値で行っている。

## 抵抗による変化

| 抵抗 | 足首の下向き可動限界 | 対象部の保持周波数 |
| --- | --- | --- |
| 100 | -10度 | 16 |
| 75 | -32.5度 | 15 |
| 50 | -55度 | 14 |
| 25 | -77.5度 | 13 |
| 0 | -100度 | 12 |

抵抗が下がるほど足首の可動範囲が広がり、対象のSpringJoint2Dの保持が弱まる。抵抗0では段階7と同じ曲がりの攻略が可能。目標角度とJointの制限を両方変更し、抵抗が残っている間はFitEvaluatorのクリアも許可しない。

すべての布を一度に柔らかくする方式ではなく、指定した曲がり部分だけを変更する。抵抗値は0未満にならず、再挑戦では100・押し当て待ち・初期角度0へ戻す。

## 検証結果

検証用コピー `Builds/Step7Validation` でUnityのコンパイルと物理検証を実施。実測は各攻略とも75、50、25、0の順に減少し、解除後にクリアした。攻略と再挑戦を2回確認した。

- 放置では抵抗が減らない。
- 抵抗が残った状態では、正しい位置へ直接置いた評価テストでもクリアしない。
- 1回の長押しで減るのは25だけ。さらに400ステップ保持しても再減少しない。
- ±0.03の細かな目標変更や、マウス解放だけでは次の押し当てを有効にしない。
- 十分に引き戻すと次の押し当てが有効になる。
- 4回の押し戻し後に曲がってクリアできる。
- 再挑戦で抵抗、押し当て状態、クリア許可、足首の初期状態が戻る。
- 動作中に布の隙間、深い食い込み、異常な座標・速度がない。
- 段階1〜7の回帰検証も成功する。

固定刻みは0.02秒。ログは本体のGit管理外の `Logs/Step8Verification.log`、成功マーカーは `STEP8_PHYSICS_VERIFICATION_PASSED`。段階1〜8すべての成功マーカーと終了コード0を確認した。

Play停止中の `Sock Physics > Verify Step 8 Physics` で再検証できる。シーンの保存確認に従う。描画確認用のBendResistanceSetup.CapturePreviewは検証コピー内のLogsに初期・押し当て・クリア姿勢を出力する。画像はカメラ描画で、GUIと実際のキー・マウス入力は含まない。操作感と案内表示はGameビューで確認する。
