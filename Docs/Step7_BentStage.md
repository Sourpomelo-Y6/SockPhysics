# 段階7: 90度ステージ

[ドキュメント一覧](README.md) / [現在のContactシーン](ContactSock_Physics.md)

> この文書は段階別の開発記録です。数値・操作・「次の段階」は当時の実装を対象にしています。現在の操作と調整はContactシーンのガイドを参照してください。

実装日: 2026-09-10

## 操作

Unity 2021.3.45f2で `Sock Physics > Open Step 7 Scene` を選び、Playする。シーンは `Assets/Scenes/BentStage.unity`。

明るい緑の脚を左ドラッグして右へ入れる。曲がり部分では直進を止め、位置を戻しながらQで足首を下向き（-90度付近）へ曲げる。脚の位置も右下へ調整し、4か所の位置表示が合ったところで静止する。条件が0.75秒続くとクリア。Rまたは再挑戦ボタンで初期状態へ戻る。

Qは角度を減らし、Eは増やす。このシーンの可動範囲は-100〜20度で、初期角度は0度。以前のシーンは従来の角度範囲と初期角度を維持する。

## 形状と物理

入口から水平に進み、円弧を通って下向きへ曲がる。円弧の中心は(0.5, -1.25)、中心線の半径は1。外側の半径は1.65、内側は0.35。外側23点、内側15点を配置し、各区間の間隔は約0.24〜0.27とする。つま先の閉じる部分は別の4点で構成する。

各点は既存のRigidbody2D、CircleCollider2D、DistanceJoint2Dを使用する。曲がり部分と下向きの区間はSpringJoint2Dで保持し、押すだけで直線へ変形しないようにする。つま先は4点で閉じる。段階6の物理計算精度設定を使用する。

短い区間にポイントを詰めすぎると、隣接していないCollider同士が押し合って伸びるため、長さに合わせて個数を減らしている。足首のモータートルクはこのシーンだけ120とし、押す力だけで勝手に90度折れ曲がるのを防ぐ。従来シーンのトルクは変更しない。

## 評価

FitEvaluatorに目標の足の角度を追加し、直線ステージの0度と今回の-90度を区別する。曲がった形状に合わせた位置目標は次のとおり。

| 点 | 目標座標 |
| --- | --- |
| 足先 | (1.5, -1.95) |
| かかと | (1.3, -0.45) |
| 足首 | (1.5, -0.5) |
| 脚の中心 | (0.75, -0.5) |

各点の許容距離0.22、静止・角度・伸びの確認、連続0.75秒の保持、クリア後の入力停止と再挑戦は段階6の仕組みを使用する。平均Fitだけではクリアにしない。

今回の範囲は形状と操作の成立。押し当て回数やBendResistanceによる解除条件は追加していない。直線シーン、以前の比較設定、Build Settingsは維持する。

## 検証方法

Play停止中に `Sock Physics > Verify Step 7 Physics` を実行する。シーンの保存確認に従う。0.02秒刻みで直進時の停止、角度・位置調整後のクリア、再挑戦、布の隙間と深い食い込みを確認する。バッチのCreateAndVerifyは段階1〜6の回帰検証も実行する。

検証ログはGit管理外の `Logs/Step7Verification.log`。カメラ画像での確認はGUIと実際のキー・マウス入力を含まないため、操作感はGameビューで確認する。

本体をUnityで開いたまま検証できるよう、Git管理外の `Builds/Step7Validation` を使用した。最終検証ログは本体の `Logs/Step7FinalVerification.log`。初期・停止・クリア姿勢の画像は検証コピー内の `Logs/Step7Initial.png`、`Step7Blocked.png`、`Step7Clear.png` に出力する。検証済みのシーンを本体のAssetsへ配置する。

実測では、直進を12秒続けても脚の中心は約(-0.41, -0.51)、足首は約0度で停止する。目標位置(-0.7, 0)へ戻し、-90度に曲げてから(0.75, -0.5)へ進めるとクリアした。Fitは約99.9%、保持時間は0.76秒。この経路と再挑戦を2回確認し、段階1〜7の検証が成功した。

検証は既定設定と記載経路を対象とし、全方向からの回り込みや、全設定の組み合わせを網羅するものではない。曲がりに沿った汎用的な進行度スコアは今回は追加せず、各部位の目標位置で評価する。
