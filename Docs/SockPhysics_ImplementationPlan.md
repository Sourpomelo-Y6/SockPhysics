# 実装計画と現在地

作成日: 2026-09-08 / 更新日: 2026-09-11

[ドキュメント一覧](README.md) / [設計仕様](SockPhysics_DesignSpec.md)

## 現在の状態

Unity 2021.3.45f2 / URP 2Dで、段階1〜8の基本機能と、上下が物理的に接触するContactシーンを実装済み。現在の確認対象はContactInsertion・ContactStraight・ContactBend。段階別の旧シーンは比較と回帰確認用に残している。

最優先の要件は「足がないときは上下の布が接触し、足を入れると押し広がり、抜くとリセットなしで閉じる」こと。見た目の塗りつぶしだけでは、この要件を満たさない。

基準サイズでは2026-09-11にContactの3シーンと段階1〜8の自動物理検証、カメラ描画確認を完了。足・脚を拡大した設定は別途調整・検証が必要であり、基準サイズの成功結果をそのまま適用しない。

## 次の優先事項

1. 足・脚の希望サイズを決め、見た目・Collider・足首の接続点・開始位置を合わせる。
2. 変更後のサイズに合わせて布の抵抗、曲がり、評価位置、検証経路を調整し、抜き差し・攻略・再挑戦を確認する。
3. 操作感が安定した後、開始画面、直線・曲がりの選択、クリア後の移動、日本語の操作案内を追加する（段階9として提案済み、未実装）。

ルーズソックス、完成版グラフィック、詳細な部位形状、データ管理の拡張は追加段階として扱う。仕様書にある全構想を実装済みとはしない。

## 現在の構成と方針

| 対象 | 主な実装 | 方針 |
| --- | --- | --- |
| 足と脚 | FootController / AnkleController | 力と足首Jointで動かす。通常の移動でTransformを直接書き換えない |
| 布 | SockController / SockPhysicsPoint / ContactSock | Colliderを連続するよう配置し、開閉方向と経路を保つ方向の復元力を分ける |
| つま先 | SockToeClosure | 物理点で終端をつなぎ、表示とリセットを管理する |
| 攻略 | BendController | 押す・十分に戻すを1組として抵抗を下げる |
| クリア | FitEvaluator | 位置・角度・静止に加え、Contactでは足が布の内側にあることも評価する |
| 検証 | Editor内の各Setup | 保存済みシーンで操作用物理処理を呼び、状態と安定性を確認する |

Joint自体に布の面の当たり判定はないため、点の間隔とColliderサイズをセットで扱う。Inspector調整を先に行い、寸法の共通設定化などは実際の変更に合わせて追加する。未使用の抽象化を先行させない。

## 検証とGit管理

操作感はGameビューで、自動化できる接触・復元・攻略条件は物理検証で確認する。速い操作、長押し、繰り返し、放置、リセットを含める。手順・検証と再生成の違い・フォント復元は[検証ガイド](Verification.md)にまとめる。

Assets、Packages、ProjectSettings、Docsを管理し、Library、Logs、Buildsなどの生成物とフォントアセットを除外する。Git LFSの設定は維持する。サイズ調整の手編集と検証済みの基準設定は区別して記録する。
