# 段階5: 足首と引っかかり

実装日: 2026-09-09

## 起動と操作

1. Unity 2021.3.45f2で `Sock Physics > Open Step 5 Scene` を選び、Playする。
2. 明るい緑の脚（Leg）を左ドラッグする。濃い緑の足（Foot）は足首Jointで追従する。
3. 最初は足首が-50度に曲がっている。そのまま右へ押すと靴下の狭い区間で止まる。
4. 脚を少し左へ戻し、中央の高さに合わせる。Eを押して表示角度を0度付近まで伸ばし、再度右へ押す。
5. Qで反対方向へ曲げられる。角度の操作範囲は-70〜30度。
6. Rまたはリセットボタンで脚・足・靴下と目標角度を初期状態へ戻す。

シーンは `Assets/Scenes/AnklePrototype.unity`。16:9、960×540以上が目安。段階1〜4のシーンとBuild Settingsは変更していない。段階4の比較パネルはこのシーンに配置せず、段階5専用の案内を表示する。

## 構成

- Leg: 横長1.5×0.4の仮形状。既存FootControllerを移動用に再利用し、回転は固定する。
- Foot: 1.6×0.5の仮形状。独立したRigidbody2DとCapsuleCollider2Dを持つ。
- HingeJoint2D: 脚の先と足の後部を接続する。脚と足の相互衝突は無効化する。
- AnkleController: Q/Eで目標角度を変更し、力の上限があるJointモーターで追従する。毎フレーム角度を直接書き換える方式ではない。
- 靴下: 上下各19点。中心間隔は通常1.3、狭い区間0.92で、布の内側の隙間はそれぞれ0.94、0.56。狭い区間は各列のPoint 07と08、その両隣は滑らかにつなぐ。

狭い区間のポイントは追加のSpringJoint2Dで保持し、足を押すだけで大きく開いてしまうのを抑える。固定壁に置き換えず、既存の布のColliderとJointで接触する。初期形状は段階3より開いており、この段階では角度と通過の関係を優先して検証する。足首角度によって縦方向に必要な幅が変わり、伸ばすと狭い区間を通せる。

部位ごとの保持によって通過抵抗を作る構成で、押した回数などの隠れた解除条件はない。引き戻しは角度調整の余地を作る操作となる。すべての攻略経路で引き戻しが必須であることまでは要求していない。

## 調整項目

- FootのAnkleController: Turn Speed（既定60度/秒）、Motor Torque（既定30）、Target Angle。
- FootのHingeJoint2D: 接続位置と角度制限。Jointの角度は初期相対姿勢を基準にするため、操作用の角度とは数値が異なる。
- 靴下のPoint 07/08: 追加SpringJoint2DのFrequency（18）とDamping Ratio（1）。保持を弱めすぎると押すだけで広がりやすい。
- SockRecoveryと脚のFootController: 既存の復元・移動パラメータ。

摩擦は従来のCollider設定を引き継ぎ、この段階では保持と足の形状で抵抗を調整した。比較設定の拡張、詳細なかかと形状、クリア判定、90度ステージは含まない。

## 検証

0.02秒刻みの物理検証で、曲げたまま押す → 引き戻す → 0度へ伸ばす → 再度押すという経路を3回確認する。最初の押し込みは600ステップ（12秒）継続し、脚が靴下の途中で止まることを確認する。調整後は脚の中心がx=1.5より奥へ進む。

加えて、足首の接続距離、角度制限、布の隣接点間隔、脚と足の深い食い込み、異常な座標・速度、リセット後の初期姿勢を検証する。目標角度に範囲外の値を渡した場合の制限と、両端角度へ回転できることも確認する。

実測では、曲げた状態の長押しで脚の中心はx=-0.76付近、足の角度は約-55.8度で止まった。脚をx=-2.5、y=0を目標に引き戻してから足首を0度へ伸ばすと、再押し込みで脚の中心がx=2.00まで進んだ。この経路を3回通過し、段階1〜5すべての成功マーカーとUnity終了コード0を確認した。

再実行はPlay停止中の `Sock Physics > Verify Step 5 Physics`。ログはGit管理外の `Logs/Step5Verification.log`。成功マーカーは `STEP5_PHYSICS_VERIFICATION_PASSED`。バッチのCreateAndVerifyでは段階1〜4の回帰検証も実施する。

描画確認用の `AnklePrototypeSetup.CapturePreview` は、初期・引っかかった状態・通過後を `Logs/Step5Initial.png`、`Step5Stuck.png`、`Step5Passed.png` に出力する。カメラ描画のみで、GUIや実キー入力の検証は含まない。操作感はGameビューで確認する。

検証は既定設定と記載経路を対象とする。別方向から回り込む操作や全パラメータの組み合わせまで保証するものではない。
